<h2>Nesudėtingų scenarijų įterpimas į HTML dokumentus</h2>

<h3>Darbo tikslas</h3>

Panaudoti JavaScript scenarijus valdomam HTML turiniui kurti.
<h3>Darbo užduotis</h3>

Sukurti kliento pusėje apdorojamų scenarijų pagrindu veikiantį skaičiuotuvą. Funkcionalumą įgyvendinti naudojant HTML formas ir JavaScript scenarijus.
<h3>Darbo reikalavimai</h3>

<h4>Funkcionalumas:</h4>
1. Skaičiuotuvas įgyvendinamas kaip HTML dokumentas. Stiliui valdyti naudoti CSS priemones, valdomam turiniui ir skaičiavimams – JavaScript scenarijus.<br>
2. Minimalus skaičiuotuvo funkcionalumas:<br>
<ul>
a) 4 pagrindiniai aritmetiniai veiksmai;<br>
b) Kėlimo kvadratu operacija;<br>
c) Kėlimo pasirinktuoju laipsniu operacija;<br>
d) Kvadratinės šaknies operacija;<br>
e) Papildomai dar reikėtų įgyvendinti 2 skaičiavimo operacijas. <br>
</ul>
3. Skaičiuotuvas turi gebėti identifikuoti begalinį skaičiavimų rezultatą (pvz., dalybos iš nulio atveju) ir suprantamai jį pateikti.
<h4>Įgyvendinimas:</h4>
1. Skaičiuotuvo sąsaja turi būti įgyvendinta klasikine skaičiuotuvo forma – valdymas įgyvendinamas mygtukais. Skaičiuotuvo elementų dizainas, išvaizda, stilius, išdėstymas grindžiamas patogumu naudoti.<br>
2. Skaičiavimo rezultatams ar kitai informacijai naudoti atskirą išvesties elementą – virtualų ekraną ar kitą analogišką sprendimą.<br>
<h4>Stilius:</h4>
1. Skaičiuotuvo sąsaja turi pasižymėti atsiliepiamumo savybėmis (angl. responsive).<br>
2. Skaičiuotuvo sąsajai įgyvendinti pasinaudoti artumo (angl. Law of proximity), panašumo (angl. Law of similarity) taisyklėmis, aprašančiomis žmonių vizualinį suvokimą.
